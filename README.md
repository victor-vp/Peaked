# Code Explanation Bot

A simple command-line tool that explains code **line by line** in plain English.  
It supports **Python**, **Java**, **C**, and **SQL**, with automatic language detection.

Perfect for beginners who want quick, readable explanations without heavy documentation.

## Features

- **Automatic language detection** (Python, Java, C, SQL)
- **Manual language selection** when detection is wrong
- **Line-by-line explanations** in simple English
- Built-in **example snippets** for all supported languages
- Optional **AI chat** (OpenAI) for free-form questions
- Clean multi-line code pasting with `/done` marker

## Supported Languages

| Language | Detection | Explanation Style |
|----------|-----------|-------------------|
| Python   | Strong    | Keywords, indentation, functions, etc. |
| Java     | Strong    | Classes, methods, System.out, etc. |
| C        | Strong    | `#include`, `printf`, pointers, etc. |
| SQL      | Strong    | SELECT, FROM, JOIN, WHERE, etc. |
